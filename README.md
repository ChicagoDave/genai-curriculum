# GenAI Curriculum

A working design for a college computer science curriculum in the GenAI era.

**Vision**: a CS degree whose product is design judgment grounded in logic — graduates who can state what acceptable working software is, to the corporate standard, and hold an AI agent to it.

**Owner**: David Cornelson
**Status**: exploring (brainstorm in progress since 2026-09-24)

## What is here

This repository is documentation only. There is no code and no test suite.

| Path | Holds |
|---|---|
| `docs/brainstorm/cs-curriculum-genai-era/overview.md` | The brainstorm summary: problem, vision, core concepts, structural patterns, and progress through the remaining brainstorm sections |
| `docs/brainstorm/cs-curriculum-genai-era/README.md` | The roster index: nineteen candidate expectations with their dive verdicts, the cohort system's markdown, and the decision log |
| `docs/brainstorm/cs-curriculum-genai-era/expectations/` | One deep dive per candidate expectation (security, testing, modularization, cost, logic, and so on) |
| `docs/brainstorm/cs-curriculum-genai-era/decisions/` | The curriculum's own decision records, `college-0001` through `college-0013` |
| `docs/brainstorm/cs-curriculum-genai-era/risks.md` | Open risks to the curriculum as designed |
| `docs/context/` | Session summaries and the project profile written by the DevArch workflow |

## Where to start

Read `overview.md` for the problem and vision, then the roster in the brainstorm `README.md` to see how each expectation was judged. The decision records explain why the curriculum is shaped the way it is; each one carries Context, Decision, Consequences, and Session sections.
